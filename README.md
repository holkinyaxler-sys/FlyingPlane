# Бумажный самолётик (Flying Plane)

Учебный Android-проект на Kotlin с отрисовкой через Canvas.

## Запуск
Откройте папку `FlyingPlane` в Android Studio, дождитесь Gradle Sync и запустите приложение. Используйте JDK 17 и Android SDK 35.

## Управление
Коснитесь игрового поля и ведите пальцем: самолётик плавно следует за пальцем в реальном времени. Отпустите палец — самолётик продолжит движение к последней заданной точке, а окружение будет прокручиваться.

## Изменения
- Исправлено направление самолётика: нос направлен вперёд, вправо.
- Самолётик следует за пальцем во время касания, без предварительного рисования всей траектории.
- Плавное перемещение и наклон в зависимости от движения.
- Бесконечное появление монет и случайных препятствий (птиц и облаков).
- Счёт, высота, магазин скинов, рекорд и экран результата.
- JVM target Java и Kotlin установлен на 17.
